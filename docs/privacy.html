Privacy Policy

Last updated: 21 September 2026.

Who runs this site

GB National Grid Live ("this dashboard") is published by UK Politics Decoded, an independent, IMPRESS regulated UK news publisher. This policy covers this dashboard specifically (hosted at nationalgrid.ukpoliticsdecoded.uk); it is separate from, but consistent with, the privacy policy on the main ukpoliticsdecoded.uk site.

What data we collect about visitors

We do not collect, store, or process any personal data about visitors to this dashboard. Specifically, this site:

  • Does not use cookies of any kind.
  • Does not use browser local storage or session storage to track you.
  • Does not run any analytics, advertising, or tracking scripts.
  • Does not require an account, login, email address, or any other personal information to use.
  • Does not set or read any first party or third party identifiers.

This dashboard is a static page; your browser fetches publicly available JSON data files directly and renders charts/tables locally. No form submissions, logins, or user generated content exist anywhere on this dashboard.

Third party requests your browser makes

When you load this page, your browser makes a small number of outbound requests to third party infrastructure, purely to fetch static files. We don't control what those third parties themselves log (e.g. standard web server access logs containing your IP address), but we don't receive, request, or use any of that data ourselves:

  • GitHub (raw.githubusercontent.com / github.com) hosts the underlying grid telemetry JSON files this dashboard displays. See GitHub's privacy statement.
  • jsdelivr.net (CDN) serves the uPlot charting library used to draw graphs. See jsDelivr's privacy policy.

We may introduce basic, privacy respecting, cookie free analytics in the future (e.g. aggregate page view counts with no personal identifiers) to understand usage of this public interest tool. If we do, this policy will be updated first and this section will describe exactly what's collected.

Data about the grid, not people

The statistics shown on this dashboard are aggregated, national and regional electricity grid telemetry — generation mix, wholesale price, carbon intensity, system frequency, and interconnector flows — sourced from Elexon and the National Energy System Operator. This is infrastructure and engineering data; it does not identify individuals in any way.

Changes to this policy

If how this dashboard collects or uses data changes, this page will be updated and the "last updated" date above will change accordingly.
